# WAYG — Are You Gay?

> A troll-style desktop joke application built with Python, made as a fun exercise in GUI programming: one question, two buttons, and a "No" button that refuses to be caught.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## Overview

WAYG poses one question, the "question of the century":

> *"Are You Gay?"*

Answering **Yes** confirms it in a deliberately over-the-top way. Answering **No** is the real challenge: the button moves away when you try to click it, so good luck catching it.

The project was built as a learning exercise in GUI programming, focusing on interactive elements, mouse events and basic event handling, not as a serious product. Keep it as a joke, and do not use it to harass anyone.

## Features

- **One-question interface** — a single, deliberately absurd question as the whole premise.
- **The evasive "No" button** — the button moves away on hover or click attempts, making "No" hard to choose.
- **Over-the-top "Yes" response** — confirming "Yes" triggers the joke's punchline.
- **Interactive GUI** — built around mouse movement and event handling rather than menus or forms.
- **Zero setup beyond Python** — no third-party GUI library is needed.

## Getting Started

### Prerequisites

- Python 3.x
- `tkinter` (comes pre-installed with Python)

### Installation

```bash
git clone https://github.com/GoldenTitab/Are-You-Gay.git
cd Are-You-Gay
```

### Run

```bash
python wayg.py
```
